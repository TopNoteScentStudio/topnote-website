Homepage and page headers. The homepage hero carries no button — it is atmospheric, not transactional.

```jsx
<Hero lines={['Top Note','Scent Studio']} subline="Experiential scent discovery"
  image="../../assets/photography/first-scent.jpg" scrollHint />
```

Pass `video` instead of `image` for a looping clip (`assets/photography/motion-01.mp4`). The photography is high-key and backlit, so keep the overlay at 0.62–0.72 — enough to hold cream type, not so much that the light in the frame dies. Inner page headers use `height="42vh"` and one line.
