Type-set Top Note wordmark — use it anywhere the logo goes (nav, footer, event pages) until an SVG export exists.

```jsx
<Wordmark size={22} tone="cream" />
```

`tone="cream"` on `deep` surfaces, `tone="deep"` on `cream` surfaces. `amber` is reserved for small accent lockups (e.g. "Powered by" footers). Never place it on a busy photo without a `deep` overlay behind it.
