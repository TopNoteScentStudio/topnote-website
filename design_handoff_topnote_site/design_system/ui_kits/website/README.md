# UI kit — Top Note marketing site

Five click-through screens built entirely from the design-system components. Open `index.html` and use the nav.

| File | Screen |
|---|---|
| `HomeScreen.jsx` | Hero → cream intro → three service cards → image CTA band |
| `ServicesScreen.jsx` | Page header → alternating ServiceBlocks → amber CTA band |
| `PartnershipsScreen.jsx` | Value prop on cream → 4-step flow → metrics cards → CTA |
| `AboutScreen.jsx` | Story on cream → photo grid |
| `ContactScreen.jsx` | Contact methods + working-looking form |
| `Shared.jsx` | `NAV`, `Section`, `PageHeader`, `SiteFooter`, `Photo` placeholder |

All copy is `[FOUNDERS TO WRITE: …]` on purpose — the founders own the words. Photography is a
mauve/terracotta placeholder block; swap `Photo` for real photoshoot images when they land.
